# ddc_onset (fork)

Fork/mirror of the **Dance Dance Convolution onset detector** — a music onset detection model extracted from DDC and packaged as a lightweight PyTorch module — kept in Robert Pelloni's rhythm-game reference library for chart-generation research (see also `robertpelloni/ddc` and `robertpelloni/odcnn`).

This copy has no root README of its own; for documentation and the canonical project, see upstream.
